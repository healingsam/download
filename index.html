⬇ 다운로드

자동으로 다운로드가 시작되지 않으면 위 버튼을 눌러주세요.
업데이트 하더라도 기존 사용자의 자료는 그대로 보관됩니다.

⚠️ "일반적으로 다운로드되지 않습니다" 경고가 떠도 정상이에요

게시자가 Healingsam Co.,Ltd 로 표시되면 안전한 정식 서명 파일입니다.

  1. 다운로드 칸의 ··· → 유지 → (확인창) 삭제 옆 ▼ → 그래도 계속
  2. 설치파일 실행 시 파란 창이 뜨면 추가 정보 → 실행

여러 분이 설치하시면 이 경고는 며칠 내 자동으로 사라집니다. 🙂
